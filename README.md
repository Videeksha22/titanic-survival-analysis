# Titanic Survival Prediction – Machine Learning Project

## Project Overview
This project analyzes the Titanic dataset to understand the factors affecting passenger survival and builds multiple machine learning classification models to predict survival outcomes.

## Dataset
The dataset contains passenger information such as age, gender, ticket class, fare, and embarkation port.

## Steps Performed
- Data loading and inspection
- Exploratory Data Analysis (EDA)
- Data preprocessing and feature engineering
- Training multiple classification models
- Model evaluation and accuracy comparison

## Machine Learning Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree Classifier
- Random Forest Classifier
- Naive Bayes

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
